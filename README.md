# Abdellah Aissane — Portfolio

Portfolio React / Vite en français et en anglais, personnalisé à partir du CV d’Abdellah Aissane. Thèmes clair et sombre, responsive.

## Développement

```sh
npm ci
npm run dev
```

## Vérifications

```sh
npm run test:i18n
npm run build
```

## Vercel

Importer le dépôt dans Vercel. Framework : Vite. Commande : `npm run build`. Sortie : `dist`. Aucun secret ni variable d’environnement requis. La configuration figure dans `vercel.json`.

## Personnalisation

Contenu français dans `src/portfolio.js`, traduction dans `src/i18n/en.js`, libellés dans `src/i18n/messages.js`. Le CV personnel n’est pas inclus dans le dépôt public. Sources factuelles dans `docs/SOURCES.md`.
